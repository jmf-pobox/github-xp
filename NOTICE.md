# Provenance and third-party material

The prompt and design documents are original project material informed by the sources cited in `docs/SURVEY.md` and `docs/RESEARCH.md`. No upstream implementation or skill body has been copied into a distributable skill.

The four surveyed skill repositories have MIT root licenses at the pinned commits recorded in the survey. Their local checkouts are ignored. Before incorporating source code or substantial adapted text, record the destination file, upstream file and commit, license, modification summary, and required copyright/license notice here.

The user-supplied PDFs and screenshots under `research/` retain their original owners' rights. This project's MIT license does not grant redistribution rights to those files. They are retained locally and excluded from Git by default. XPlanner and XPlanner+ are historical references; no code or artwork from them is included in the planned package.
